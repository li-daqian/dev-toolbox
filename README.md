# dev-toolbox
Installation and configuration of personal developer tools.

## Installation (Only for ubuntu)
```bash
curl -fsSL  "https://raw.githubusercontent.com/li-daqian/dev-toolbox/main/install.sh?$(date +%s)" | sh
```

## oh-my-zsh
```bash
curl -fsSL  "https://raw.githubusercontent.com/li-daqian/dev-toolbox/main/oh-my-zsh/install.sh?$(date +%s)" | sh
```

## rime (Only for linux)
